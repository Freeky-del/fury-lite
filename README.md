# Installation
1. Download the [repository](https://github.com/Freeky-del/fury-lite/archive/refs/heads/main.zip) as a `.zip`
2. Extract all files from the `.zip`
3. Open the `.sln`
4. Make sure to set the project to `Release x64`
5. Build it by pressing `Ctrl + B`
6. Read [how to use](#how-to-use)

# How to use
1. Make sure to disable `VulnerableDriverBlocklistEnable` in RegEdit, [how to do](https://windowsreport.com/microsoft-vulnerable-driver-blocklist/)
2. Restart your pc and turn off `Secure Boot` in the BIOS
3. [Download the KMDF](https://github.com/Freeky-del/KMDF-Fury/tree/KMDF)
4. Map the driver, [kdmapper recommended](https://github.com/TheCruZ/kdmapper)
5. Open CS2
6. Open _**Fury Lite**_
7. Enjoy
> [!Note]
> Once successfully opened, in the top-left corner of the screen there will be write _**Fury Lite - v1.0.0**_

> [!Important]
> - Press INS to show/hide the menu
> - Press END to close the cheat
